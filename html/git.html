Git - всему голова!

  • git init — создает новый локальный репозиторий.
  • git clone — клонирует удаленный репозиторий на локальный компьютер.
  • git add — добавляет изменения в индекс (подготавливает к коммиту).
  • git commit -m "сообщение" — фиксирует изменения с комментарием.
  • git push — отправляет изменения в удаленный репозиторий.
  • git pull — загружает изменения из удаленного репозитория.
